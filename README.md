# Placement Prediction System

## Overview

The Placement Prediction System is a machine learning based web application developed to predict a student’s placement probability based on academic performance, technical skills, projects, internships, certifications, and aptitude-related factors.

The system helps students understand their current placement readiness and provides personalized suggestions to improve their chances of getting placed.

---

# Features

* Student placement probability prediction
* Skills analysis and domain-wise scoring
* Personalized skill recommendations
* Skills radar chart visualization
* Admin dashboard for managing student records
* Student login and profile management
* Placement status prediction (Placed / Not Placed)
* Responsive and user-friendly interface

# Installation Steps

## Clone the Repository

```bash
git clone <repository-link>
```

## Navigate to Project Folder

```bash

```

## Install Required Packages

```bash

```

## Run the Application

```bash

```
